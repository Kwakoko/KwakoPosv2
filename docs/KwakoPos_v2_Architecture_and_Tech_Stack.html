1. High-Level Global System Layout Drawing

KwakoPos v2 is architected as an Offline-First, Multi-Tenant Retail Operating System. The platform decouples client-side transactional execution (cash register checkout, barcode scanning, shift balancing) from cloud persistence via an optimistic local store and transactional outbox synchronizer.

Figure 1.0 — High-Level End-to-End System Layout & Multi-Tier Runtime Pipeline

● Zero Latency Counter Execution

All cashier sales, barcode lookups, discounts, and payment tenders execute against the client-side IndexedDB engine in under 5ms, guaranteeing POS counter operations continue during internet blackouts.

● Idempotent Cloud Synchronization

Transactions are enqueued into an immutable client Outbox with client-generated UUID idempotency keys. On internet restoration, the Outbox synchronizer drains records to Fastify with zero duplicate sales.

3. Multi-Tenant Data Isolation & Security Architecture

KwakoPos v2 implements enterprise multi-tenancy with Strict Foreign Key Scoping. Tenants operate in shared container infrastructure while maintaining absolute logical isolation across database records, local storage caches, and sync queues.

Figure 3.0 — Multi-Tenant Row-Level Security & Tenant Workspace Boundary Architecture

Security Architecture Principles

Pillar Implementation Specification Verification Gate
Tenant Isolation Every database query, API route, and IndexedDB table is scoped by tenantId. No query is permitted to query records across tenant boundaries. PASS Tested via tenant-isolation.test.ts
Branch Isolation Stock movements, cash drawers, and physical tills are strictly constrained to branchId with permission-gated branch switching. PASS SystemAppShell context guard
Cryptographic Receipts Each issued receipt includes a SHA-256 digital signature computed from transaction timestamp, customer, total, and tenant fiscal key. SHA256 TRA VFD Compliant
Zero-Demo Policy Zero synthetic, placeholder, or mock business data in production builds. Real domain records only. CERTIFIED 10/10 Cleanliness Pillars
